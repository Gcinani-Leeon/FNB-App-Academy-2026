# Introduction to Python: Mobile and Web application development

## Module Learning Outcomes
By the end of this module, you will be able to:
- Apply User-Centred Design (UCD): Design intuitive, accessible interfaces and map technical feature requirements directly to business goals and user personas.
- Implement Advanced Programming Concepts: Apply Object-Oriented Programming (OOP) paradigms, modular architecture, file handling, and robust exception management in Python.
- Build Cross-Platform UIs: Construct responsive, multi-view mobile and desktop applications using the Flet framework.
- Integrate External APIs: Fetch, parse, and handle live asynchronous data feeds using REST APIs and JSON objects.
- Deliver an End-to-End Capstone Application: Design, test, debug, and present a functional application from initial concept through final peer/facilitator evaluation.
