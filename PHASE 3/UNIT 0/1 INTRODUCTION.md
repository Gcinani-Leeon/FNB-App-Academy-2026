# FUNCTIONS and USER -CENTRED DESIGN

This section explores the foundations of programming logic and user-centred design principles.

*The following topics will be covered:*
- **Functions:** Learn how to write modular, reusable blocks of code by defining custom functions, passing parameters, and returning values.
- **User-Centered Design and the 5-Step Process:** Explore core design-thinking principles to understand users and map out effective software solutions.
- **Design Walkthrough – Community Events App:** Walk through a practical case study to see design thinking applied to a real-world application.
- **Wireframing, Inclusive Design, and Scoping:** Learn how to sketch screen layouts, account for diverse user needs, and outline product requirements.
- **Scoping and Prioritizing:** Master the framework for distinguishing between must-have and nice-to-have features for your project.
